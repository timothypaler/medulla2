# Static export

This independent React + Vite project excludes Sites authentication, server routes, Worker integration, Site identity, credentials and node_modules. Its compiled HTML works with adjacent artwork and needs no application server.

Root index.html and dist/index.html are identical. The Pages ZIP places dist contents at its root. The source ZIP contains editable source, original licensed illustrations, exact source/view target mappings, checks and a ready-to-open root preview.

The anatomy/ directory and body-selector-v3.webp must remain beside index.html after extraction and upload. No external fetch supplies study content or source artwork. Reference links require internet access. Progress remains in the current browser and origin; file previews and private browsers may limit storage.
