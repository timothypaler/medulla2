# Respiratory and regional atlas update

39 identification regions; 402 targets. The two new respiratory regions contain 26 upper-tract and 47 lower-tract targets across 13 views. The 16 later regional/clinical sets now use 45 detailed source views, including dissections, sections and teaching networks. Source-view selection follows each target automatically. Exploration has an accessible view menu; zoom reaches 400%.

The brain is a continuous lateral image with its visible brainstem and cerebellum. The body selector uses an anonymous, softly shaded clothed mannequin for navigation.

Existing 329 target identities, 64 applied cases, timers, per-letter capacity, instant grading, retries and saved-progress keys are retained. The pathway still has 60 concise study guides and 243 objectives; this update does not assess every objective or claim exhaustive Year 1–2 coverage.

Respiratory convention: upper tract comprises nose, nasal cavity, sinuses and pharynx; lower tract begins at the larynx. Coverage is major structures in the selected source figures, not every bronchopulmonary segment, subsegment or variation. New target pins and teaching interpretations need anatomist review before formal assessment.

Validation: 402 target keys, per-view membership and source asset existence; all 64 applied-case canonical matches; capped input, grading and timer boundaries; TypeScript; hosted production build and static Pages build. Browser checks cover navigation, source-view matching, zoom/expansion, starting clues and grading. Automated checks validate app data and behaviour, not clinical accuracy.

Artwork attribution and individual licences are in ANATOMY-ARTWORK-CREDITS.md and the in-app source panel. No proprietary Netter or atlas-app artwork was copied. The static export keeps a classic inline JavaScript runtime and adjacent relative artwork, with every file below the Pages per-file limit.
